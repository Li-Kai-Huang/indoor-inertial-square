# 基於智慧型手機慣性感測器之室內軌跡追蹤與誤差分析系統
**Indoor Inertial Square - 專案開發與演算法實作報告**

---

## 1. 專案摘要 (Abstract)
本專案旨在開發一款 Android 應用程式，利用智慧型手機內建之慣性感測器（Inertial Sensors），實現室內環境下的行人航位推算（Pedestrian Dead Reckoning, PDR）與慣性導航（INS）。
系統專為「封閉矩形軌跡」的學術測試而設計，透過線性加速度的二次積分來推算位移，並針對手機感測器常見的「靜態漂移」與「轉彎手震」問題，實作了零速度更新（ZUPT）與轉彎穩定器等抗漂移演算法。最終，系統能即時繪製使用者的行走軌跡，並精確計算出閉合誤差（長度與角度）及所圍繞之多邊形面積。

---

## 2. 系統架構與核心演算法

本系統的核心引擎運作於背景的 `TrackingService`，以 50Hz (Sensor Delay Game) 的高頻率即時擷取並融合感測器數據。

### 2.1 感測器融合 (Sensor Fusion)
* **方向擷取 (Heading)**：監聽 `TYPE_ROTATION_VECTOR`，利用 Android 系統融合陀螺儀、地磁儀與重力感測器的四元數矩陣，提取出相對於真實世界北方的方位角（Azimuth）。
* **線性加速度 (Linear Acceleration)**：監聽 `TYPE_LINEAR_ACCELERATION`，此數據已由系統底層濾除地球重力（$9.81 m/s^2$），提供純粹的裝置移動加速度。透過乘上方位角的 $\sin(\theta)$ 與 $\cos(\theta)$，將手機座標系下的加速度投影至真實世界的二維平面（X軸向東，Y軸向北）。

### 2.2 加速度二次積分與抗漂移策略
傳統的加速度二次積分（$X = \frac{1}{2}at^2$）在手機端極易因為微小雜訊產生無窮放大的漂移誤差。本專案採用以下四種聯合策略來保證軌跡的絕對穩定：

**1. 零速度更新 (Zero Velocity Update, ZUPT)**
> 當系統偵測到當前加速度的向量長度（Magnitude）小於使用者設定的「計步門檻」時，系統強硬介入，將目前的推算速度 $V_x$ 與 $V_y$ **瞬間歸零**。這確保了使用者站立不動時，軌跡絕對不會產生任何靜態漂移。

**2. 轉彎穩定器 (Turn Stabilizer)**
> 行人在轉彎時（例如矩形的 90 度轉角），手臂的揮動會產生極大的離心與橫向加速度。系統內部維護了一組「低通濾波平滑方位角 (Smoothed Azimuth)」。若當前方位角與平滑方位角之差大於 0.2 rad（約 12 度），判定使用者正在瞬間轉向，此時強制觸發 ZUPT 暫停位移積分，完美過濾掉轉彎時的橫向雜訊，確保畫出完美的直角。

**3. 速度衰減 (Velocity Decay)**
> 在處於移動狀態時，將每一幀的速度乘上一個衰減常數（如 $0.9$），強制將積分產生的速度誤差收斂，避免因積分發散導致軌跡無限拉長。

**4. 距離比例常數 (Distance Scale)**
> 作為最終的線性補償，將二次積分算出的位移量乘上比例常數，以還原真實世界中的公尺單位。

## 3. 誤差分析與面積精算機制

為了量化實驗結果，系統在 `MapScreen` 前端介面中實作了嚴格的幾何計算：

### 3.1 閉合誤差 (Closure Error)
當使用者聲稱完成一個封閉圖形並回到原點時，系統計算當前最終座標 $(X_{final}, Y_{final})$ 與起點 $(0, 0)$ 之間的幾何關係：
* **長度誤差**：$Error_{length} = \sqrt{X_{final}^2 + Y_{final}^2}$ (單位：公尺)
* **角度誤差**：利用 $\text{atan2}(Y_{final}, X_{final})$ 算出最後偏移位置相對於起點的角度。

### 3.2 封閉面積計算：鞋帶公式 (Shoelace Formula)
當使用者按下「計算面積」時，系統利用多邊形面積的經典數學模型 **Shoelace Formula**，將軌跡串列中的每一個節點交叉相乘，自動閉合最後一點與第一點，得出極度精確的內部面積：
$$ Area = \frac{1}{2} \left| \sum_{i=1}^{n-1} (x_i y_{i+1} - x_{i+1} y_i) + (x_n y_1 - x_1 y_n) \right| $$

## 4. UI/UX 介面設計與功能操作

採用最新的 **Jetpack Compose** 聲明式 UI 框架撰寫，整體以「極簡高級灰白 (Minimalist Grey)」風格呈現，具備專業儀表板的學術質感。

* **雙互動畫布**：提供能自動縮放與置中（Auto-Scaling & Centering）的 Cartesian Canvas，即時繪製湛藍色的行走軌跡與紅色當前節點，並帶有淺色十字坐標軸供對齊。
* **即時參數校準區**：
  * 滑桿直接綁定 Kotlin Coroutines `StateFlow`，調整「計步門檻」與「步長」時，數值會以毫秒級同步至背景 Service。
  * **自動校準精靈**：提供一個 AlertDialog 讓使用者輸入「實際走過的直線距離」，系統會利用該數值除以系統目前的「測量距離」，自動反推並覆寫最精確的 Distance Scale。
* **操作與重置**：包含一鍵「計算面積」以及一鍵「重新歸零」。重新歸零透過 Android `Intent` 傳遞指令，瞬間洗掉資料庫舊軌跡並重置感測器變數，讓多次實驗的銜接如絲般順滑。

---

## 5. 總結
本專案成功克服了純粹使用手機感測器進行雙重積分所帶來的災難性漂移問題。透過極具巧思的 **ZUPT 門檻判定** 以及 **轉彎防偏移濾波器**，這套系統能非常穩定且精準地還原使用者在室內走出的矩形軌跡，並具備全套的科學數據量化能力（閉合誤差、面積、自動校準），是一套非常完整且具備實用價值的學術級追蹤與分析工具。
